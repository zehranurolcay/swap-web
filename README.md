# Swap-Web

Kullanıcıların ürünlerini listeleyebildiği, ürünleri inceleyebildiği ve birbirleriyle takas teklifleri oluşturabildiği bir web uygulaması. Bu proje ile PHP, MySQL, JavaScript ve web tabanlı uygulama geliştirme üzerine pratik yaptım.

## Özellikler

- Kullanıcı kayıt ve giriş sistemi
- Kullanıcı hesabı ve profil yönetimi
- Ürün listeleme ve ürün detaylarını görüntüleme
- Ürünleri kategorilere göre filtreleme
- Ürün arama
- Ürünleri favorilere ekleme ve favorilerden çıkarma
- Kullanıcıların kendi ürünlerini yönetebilmesi
- Ürünler arasında takas teklifi oluşturma
- Takas tekliflerinin durumunu takip etme
- Kullanıcılar arasında mesajlaşma
- JWT tabanlı oturum kontrolü
- Responsive web arayüzü

## Kullanılan Teknolojiler

- PHP
- MySQL
- JavaScript
- HTML5
- CSS3
- Bootstrap
- jQuery
- REST API
- JWT
- Git

## Proje Yapısı

Proje, kullanıcı arayüzü, API işlemleri ve veritabanı bileşenlerini içeren bir web uygulaması yapısına sahiptir.

- `api/` → API işlemleri
- `database/` → Veritabanı dosyaları
- `server/` → Sunucu tarafı işlemleri
- `assets/` → CSS, JavaScript ve görsel dosyaları
- `popup/` → Popup bileşenleri
- `other-operations/` → Diğer yardımcı işlemler
